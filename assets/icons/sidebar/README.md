# Sidebar icons

Lucide 1.21.0, from https://github.com/lucide-icons/lucide/tree/1.21.0/icons.

Original vector geometry, 24px viewBox and 2px rounded strokes are preserved. The source stroke is set to white for standalone SVG image rendering; SidebarIcon applies explicit tint for controls on light surfaces.

Lucide aliases: `BarChart3` = `chart-column`; `UserCircle2` = `circle-user-round`. See LICENSE for attribution and redistribution terms.
